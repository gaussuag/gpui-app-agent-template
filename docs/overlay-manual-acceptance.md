# Overlay 人工验收

启动：在仓库根目录运行 `cargo run --locked -p desktop -- --overlay-demo`。
建议用两个普通记事本窗口作为宿主；测试结束后关闭 Demo 即可。

## 已有证据，无需重复

- 用户已确认普通预览与 Overlay 的系统剪贴板复制、删除、粘贴正常。
- 原生专项已覆盖中文输入法、Tab/Shift+Tab、Dialog/Sheet、菜单、通知。
- 已检查当前 200% 环境下的 tooltip 与滚动截图。

## 本轮使用体验确认

| 项目 | 操作 | 预期 | 用户结果 |
|---|---|---|---|
| 内容保留 | 附着记事本，在交互模式输入文字、点击计数；切 HUD 再切交互 | 同一会话内文字、计数保留；HUD 点击和滚轮作用于宿主 | 用户确认通过（2026-09-22） |
| 显隐恢复 | 保持同一会话，切其他应用，再切回宿主；最小化并还原宿主 | 失去前台时隐藏；恢复后重新对齐；内容不重置 | 用户确认通过（2026-09-22） |
| 切换宿主与退出 | 从记事本 A 切换到 B；关闭 B 后重新选择 A；最后关闭 Demo 控制窗口 | 旧 Overlay 消失，可重新附着；关闭控制窗口后无残留 Overlay | 用户确认通过（2026-09-22） |

上述项目已有自动化覆盖；人工结果用于确认真实使用流程和感知表现，
无需反复执行，也不替代代码检查。

## 保留的环境验收

- **60Hz 项用户人工验收通过**：用户确认当前两个显示器均为 60Hz，
  功能正常，并明确接受该项、不再补测刷新率归属。已有几何耗时测试通过；
  历史样本未记录窗口所在显示器及刷新率，因此不补称为已确认的 60Hz 定量测量。
- 跨屏与多桌面：用户确认测试正常（2026-09-22）。
- 运行时 100%→150%→100%：修复后将 Overlay 附着到“设置”，不拖动窗口，
  用户确认 Overlay 随系统窗口自动适应。详见 [DPI 修复证据](overlay-dpi-evidence.md)。
- 负坐标显示器：尚未单独确认，继续保留为未完成项。

反馈格式：`内容保留：通过/异常；显隐恢复：通过/异常；切换与退出：通过/异常`。
异常请附操作步骤及实际表现；统一回归暂按用户要求不运行。
