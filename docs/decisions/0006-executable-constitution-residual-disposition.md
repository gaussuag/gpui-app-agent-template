# ADR 0006: Accepted contract limitations (superseded)

- Status: superseded
- Superseded by: [ADR 0008](0008-spec-driven-development.md)

This decision accepted remaining limitations in the former machine-contract
system rather than expanding it without observed ordinary-task failures.
The specific findings and dispositions remain in Git history at `907b7cb`.

The system is now retired. The useful principle remains: add a persistent
control for a demonstrated problem, and prefer simpler technical checks and
human acceptance over speculative governance machinery.
