# Working in this repository

On entry, read [base rules](agent-foundation/BASE-AGENTS.md) and
[project map](docs/project-guide.md). These two documents provide the shared
workflow and this repository's concrete owners, commands and acceptance paths.
Read the nearest scoped `AGENTS.md` before editing its files.

Implement the supplied spec using current source and locked dependencies.
Preserve user changes. Deliver coherent local commits unless the user asks for
uncommitted work. Select checks by impact from the project map; a small edit or
intermediate commit does not require the complete gate.
